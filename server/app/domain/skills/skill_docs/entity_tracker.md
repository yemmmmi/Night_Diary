# 实体追踪技能

## 一句话摘要
当用户提及具体人物时，查询实体图获取关系和情感关联信息。

## 触发条件
当 intent 为 entity_query 时激活（分数 0.9）；
文本包含人物称谓且同时包含"怎么样""怎么了""最近"时激活（分数 0.8）；
仅包含人物称谓时分数 0.5。

以上为第一阶段规则打分（规则地板）。当规则分数低于阈值 0.3 且本轮意图为
弱信号意图（情绪/回溯/建议/实体类）时，该技能进入灰色名单，由注册表的
第二阶段轻量 LLM 判定统一补打语义分，最终分数取 max(规则分, LLM分)——
LLM 只能救回漏检（如词库未覆盖的昵称），不能否决规则已命中的激活。
LLM 失败时降级为纯规则结果。

支持的人物称谓包括：妈妈、爸爸、老公、老婆、男友、女友、儿子、女儿、
老板、同事、老师、朋友。

## 能力详述
场景 2（多轮对话）专用技能。当用户询问某个具体人物的近况或关系状态时，
触发实体图查询。

执行时返回触发标记，提示上游 Agent 在上下文中注入相关实体信息
（来自实体图 EntityGraph，包括人物关系、交互频率、情感关联等）。
实际实体查询由上游 EntityGraphRepository 完成，本技能负责声明查询需求。

依赖数据库（requires_db=True）。

## 调用方式
- 参数: context (dict)，包含 diary_content、user_id、intent 等
- 返回: 实体图查询触发标记字符串

## 输出示例
[entity_tracker] 已触发实体图查询，请在上下文中包含相关实体信息。
