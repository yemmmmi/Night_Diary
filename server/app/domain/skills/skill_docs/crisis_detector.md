# 危机检测技能

## 一句话摘要
识别日记中的极端负面情绪并触发安全干预，返回心理援助资源。

## 触发条件
当日记文本包含"想死""不想活""自杀"等严重负面信号，或用户 intent 为
emotional_support 时激活。负面信号累计达到 3 个以上也会触发。

## 能力详述
基于共享的 EmotionEstimator 估算情绪分数（单一情绪词典来源）。

- 若检测到严重信号（has_severe_signal），激活分数直接为 1.0。
- 若 intent 为 emotional_support，激活分数为 0.8。
- 若情绪分数低于危机阈值（crisis_threshold），触发升级响应协议，
  返回心理援助热线资源（全国心理援助热线 400-161-9995、北京心理危机
  研究与干预中心 010-82951332、生命热线 400-821-1215）。
- 若情绪状态正常，返回正常结论。

该技能不依赖 LLM，纯本地关键词启发式估算，token 消耗极低。

## 调用方式
- 参数: diary_content (str)、user_id (str)
- 返回: 包含危机等级、匹配关键词和援助资源的文本字符串
