# 洞悉技能

## 一句话摘要
以克制、理性的心理视角拆解用户输入的情感本质，帮用户看清自己。

## 触发条件
命中「我怎么了」「为什么我总是」等自我觉察问句（强规则），或意图分类判定为
insight 时激活。也可由用户在输入框手动选择「洞悉」触发。

## 能力详述
先用一两句客观复述用户输入的核心，再拆解三个层面：表面在说什么、情绪信号是
什么、背后可能的心理需求。可参考离线心理学知识库（`retrieve_psychology`）的
理论视角，但只作为参考角度，绝不贴诊断标签。推测一律用「可能」「也许」，结尾
给一个自我观察问题而非行动指令。缺少 LLM 时返回 None，回退到普通对话。

## 调用方式
- 参数: content（用户输入文本，截断至 2000 字）
- 返回: SkillRunOutcome，含 matched_theories / observations

## 输出示例
先复述，再分「表面 / 情绪 / 需求」三层分析，末句抛出一个向内观察的问题；
总长控制在 300 字以内，无开场白。
