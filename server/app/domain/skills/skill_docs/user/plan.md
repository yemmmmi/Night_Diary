# 计划技能

## 一句话摘要
把用户的意图整理成结构化计划（目标 / 里程碑 / 可执行任务）。

## 触发条件
命中「做个计划」「怎么规划」等指令（强规则），或带有量化目标（「30 天」
「每天 4 小时」）与自我改变动词的句子（目标规则），或意图分类判定为 plan 时
激活。也可由用户在输入框手动选择「计划」触发。

## 能力详述
把用户模糊的意图拆解为目标、里程碑与可执行任务，形成结构化计划草案。计划
以提案形式给出，仍需用户确认后才落库，技能本身不直接写入计划表。缺少 LLM
时返回 None，回退到普通对话。

## 调用方式
- 参数: content（用户输入文本，截断至 2000 字）
- 返回: SkillRunOutcome，含计划草案文本

## 输出示例
目标一句话 + 若干里程碑 + 每个里程碑下 2-4 条可执行任务；语言克制、可落地，
不堆砌激励性口号。
