# 记录技能

## 一句话摘要
把用户的口述转写为一篇客观日记并入库，不虚构、不添改、不加评价。

## 触发条件
命中「帮我记一篇日记」「写篇日记」「记一下」等明确记录指令（强规则），
或意图分类判定为 record 时激活。也可由用户在输入框手动选择「记录」触发。

## 能力详述
以「你」为主语、第三人称视角，把用户口述转写为连贯的日记正文。严格基于
用户实际说出的内容：不虚构细节、不补充未提及的信息、不添加感想或情绪渲染，
保留时间、地点、人物与事件经过。转写结果经 `diary_service.create_entry`
落库。缺少 LLM 时降级为原样存储用户输入（仍满足「不虚构」）。

## 调用方式
- 参数: content（用户口述文本，截断至 2000 字）
- 返回: SkillRunOutcome，含 diary_id / date / content

## 输出示例
一段以「你」为主语、按时间或逻辑顺序组织的客观日记正文；无标题、无日期抬头、
无任何解释或开场白。
