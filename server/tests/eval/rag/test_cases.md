# RAG 检索评估 — 标注说明

> 本文件解释 `test_cases.json` 中每条查询的检索意图、相关日记（gold）判定理由与边缘情况。
> 语料 `diaries.json`（30 条）与查询 `test_cases.json`（20 条）均为**人工固定标注**，提交到仓库，eval 运行时不得随机生成或改写。

## 数据集设计原则

1. **关键词 vs 语义的刻意分离**：关键词意图的查询与其 gold 日记**共享表层词**（利于 BM25）；语义意图的查询**刻意避开 gold 日记中的表层词**，逼迫向量分支承担召回（利于 dense embedding）。这样四种方案的对比才有信息量，而非互相重复。
2. **diary 粒度评估**：`HybridRetriever` 返回结果按 `diary_id` 去重，因此 gold 与评估都以 `diary_id` 为单位，与生产检索输出一致。
3. **相关数 1–3**：每条查询标注 1–3 个相关日记，既能算 Recall@5/MRR/nDCG@5，又避免在 30 条小语料上 gold 过密导致指标饱和。
4. **分词注意**：BM25 使用 jieba 并丢弃单字 token（`len >= 2`）。因此查询里的单字（如「猫」）对 BM25 无效，gold 的命中依赖多字词（如「领养」「猫咪」）。标注时已考虑这一点。

## 逐条标注理由

### 关键词意图（gold 含查询表层词，BM25 应能直接命中）

- **q01 `失眠` → d01**：d01 含「失眠」原词。d02 虽同属失眠主题但用「睡不安稳/睡眠质量」表达、不含「失眠」，故**不计入 q01 的 gold**（留给语义查询 q05）。这制造了一个"关键词查全率天然受限"的诚实样本。
- **q02 `红烧肉` → d17**：仅 d17 提到红烧肉，唯一相关。
- **q03 `健身房撸铁` → d04**：d04 含「健身房」「撸铁」「力量训练」。d03 是晨跑、属运动但非健身房，不计入（留给语义 q09）。
- **q04 `领养猫咪` → d21**：d21 含「领养」「猫咪」。注意「猫」单字会被 jieba 丢弃，靠「领养」「猫咪」命中。

### 语义意图（gold 不含查询表层词，依赖向量召回）

- **q05 `晚上总是睡不着觉` → d01, d02**：两条都写失眠/睡眠差。d02 完全不含「失眠」「睡不着」原词（用「睡不安稳」），是纯语义召回样本；d01 含「睡着」近似。
- **q06 `和家里人发生了矛盾` → d05**：d05 用「吵架/争执/催婚」，不含「矛盾」「家里人」。语义等价。
- **q07 `失去一段感情的痛苦` → d09**：d09 用「分手/失恋/眼泪」，不含「痛苦」「失去」。
- **q08 `独自在异乡感到寂寞` → d19**：d19 用「孤独/一个人/陌生的城市」，不含「寂寞」「异乡」。
- **q09 `运动锻炼让人精神变好` → d03, d04**：d03 晨跑「神清气爽/精力充沛」、d04 健身房，均表达运动后状态，不含「锻炼」「精神变好」原短语。

### 情绪意图（按情绪极性聚类，gold 跨多条）

- **q10 `最近特别焦虑` → d08, d25, d01**：d08 裁员焦虑、d25 考研焦虑（两者含「焦虑」原词，BM25 也可命中），d01 加班压力失眠（语义相关、不含「焦虑」）。混合命中能力测试样本。
- **q11 `感到开心快乐的时候` → d07, d18, d27**：升职、老友聚餐、春天，三条都是正向情绪但表达各异。
- **q12 `心情低落很难过` → d09, d26**：分手的难过 + 雨天的低落。d26 含「心情低落」近似词。
- **q13 `压力大想要放松一下` → d12, d30, d23**：海边日落放松、冥想放松、周末懒觉，三条均为"放松/解压"语义。

### 时间意图（注意：检索器无时间过滤，实为内容召回）

> `HybridRetriever` 当前**不做时间范围过滤**，因此"时间意图"查询本质是对"提及该时段的内容"做召回，而非按日期筛选。此处保留时间类查询用于记录未来接入时间过滤后的对照点。

- **q14 `周末是怎么度过的` → d23**：d23 明确写「周末/睡懒觉/休息日」。d17 虽含「周末」但主题是做菜，按"询问周末如何度过"的主旨，d23 更贴切，d17 不计入（边缘，见下）。
- **q15 `春天的好心情` → d27**：d27 写樱花/春天/心情明媚。

### 复合意图（多约束，需同时满足）

- **q16 `工作压力大到睡不好觉` → d01**：需同时满足"工作压力"+"睡眠"。d01 兼具加班压力与失眠。d22 只有加班疲惫无失眠，不计入。
- **q17 `和妈妈和好之后一起吃饭` → d06**：需"和解"+"一起吃饭"。d06 精确匹配；d05 是吵架（相反），不计入。
- **q18 `出去旅行看风景放松心情` → d11, d12**：大理环湖、海边日落，旅行+风景+放松三要素齐备。
- **q19 `生病了一个人在家休息` → d15**：感冒发烧在家休息，复合命中。
- **q20 `学习编程这门新技能` → d24**：自学 Python 编程。

## 已知边缘 / 争议样本（评估时可据此解读失败案例）

- **q01 vs q05 的失眠拆分**：d02 只算 q05 不算 q01，是故意制造的"关键词查全受限"案例。若 BM25 在 q05 上 Recall 偏低属预期。
- **q14 周末的归属**：d17（周末做菜）未计入 q14。若某方案把 d17 排进 top-5，不算错得离谱，但按主旨判 d23 才是 gold。
- **q10/q13 的三 gold 混合性**：含原词命中（d08/d25 的"焦虑"）与纯语义命中（d01），用于观察混合检索能否同时覆盖两类。
- **情绪类查询的 gold 边界**：情绪是连续的，理论上 d16（体检担忧）也带焦虑色彩，但其核心是健康担忧而非"焦虑情绪本身"，故未计入 q10，避免 gold 过度泛化。
