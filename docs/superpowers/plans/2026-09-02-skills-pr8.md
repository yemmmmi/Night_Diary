# PR8 实施计划 — 三大 Skill：记录 / 洞悉 / 计划

> 分支 `feat/skills-pr8`（基于 main @ PR7 merge）。

## 目标

在笔谈（聊天）中实现三个 skill，由意图路由自动触发：

1. **记录**：把用户口述转写为客观日记（主语用「你」、不虚构、不加料），录入日记系统。
2. **洞悉**：结合离线心理学知识库，拆解用户输入，给出克制理性的分析，帮用户理清情感本质。
3. **计划**：根据用户输入自动生成计划并录入计划系统，支持三种模板（数据结构重构）。

## 架构决策

- **触发方式**：意图路由（关键词规则优先 + light LLM 四分类兜底：record/insight/plan/chat）。未命中或 LLM 不可用一律走普通聊天，保证零回归。
- **结果呈现**：`chat_messages` 表加 `skill_result` TEXT 列（JSON），assistant 消息携带结构化结果，历史可回放；前端 LetterMessage 渲染结果块。
- **流式路径**：skill 命中时不走逐字流式，一次性产出完整文字（skill 是确定性流程）。
- **计划数据结构**（向后兼容，旧计划 template=NULL 走原 tasks UI 不动）：
  - `plans.template` VARCHAR(20) NULL：`checkin_total`（累计打卡）/ `timer_daily`（每日计时）/ `milestones`（学习节点）
  - `tasks.link` VARCHAR(500) NULL：模板3 节点参考链接
  - 新表 `plan_checkins`（ORM 建表，create_all 自动创建）：打卡/计时记录
- **联网搜索**（模板3）：`web_search_service`，Tavily（有 key）→ DuckDuckGo（ddgs 库）→ LLM 内置知识降级（标注未验证）。单次生成最多 5 次查询；交叉验证：节点需 ≥2 独立域名来源才挂主链接。
- **洞悉知识库**：`app/domain/knowledge/psychology.py` 静态条目（理论 + 关键词），关键词匹配 top-3 注入 prompt，离线可用。

## 模板语义

| 模板 | 进度 | 打卡行为 | 完成条件 |
|---|---|---|---|
| checkin_total（减肥30天） | n/30 (n/30%) | 每日一次，+1 | n ≥ target_value |
| timer_daily（每日学4h） | 今日累计秒/目标秒 + 坚持天数 | 开始计时（running）→ 手动停止；累计 ≥4h 当天自动完成并弹窗 | 连续天数由前端算 |
| milestones（学剪辑） | done 节点/总节点 (%) | 点击进入节点列表，勾选完成（复用 task PATCH） | 全部节点 done |
