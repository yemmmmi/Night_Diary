# 夜记用户指南

夜记是一款 Web 端心理陪伴日记应用，通过浏览器访问，支持多用户账号。

## 访问

1. 打开浏览器，访问部署地址（如 `http://localhost` 本地开发或生产域名）。
2. 注册账号：填写邮箱、密码、昵称。
3. 登录后进入引导页：配置称呼，可选配置 AI 模型（DeepSeek）。

数据由后端统一存储（MySQL + ChromaDB），各用户数据互相隔离。

## 数据存储

数据存储在服务器端 Docker 命名卷中：

| 卷 | 用途 |
|----|------|
| `mysql_data` | 日记、会话、账号等结构化数据 |
| `redis_data` | 会话缓存、JWT 黑名单 |
| `neo4j_data` | 实体关系图（可选） |
| `backend_data` | ChromaDB 向量库、备份、日志 |

## 常见问题

| 现象 | 处理 |
|------|------|
| 登录后无响应 | 检查网络；清除浏览器缓存后重试 |
| AI 回信为空或模板化 | 检查设置页 LLM 配置（API Key、Base URL） |
| 模型下载慢 | 首次约 200MB，正常；可配置 `HF_ENDPOINT` 使用国内镜像 |

## 账号管理

- 修改密码：设置页 → 账号安全
- 注销账号：联系管理员（数据将一并删除）
