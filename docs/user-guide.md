# 夜记用户指南

夜记是一款本地桌面日记应用，数据保存在你的电脑上，无需登录。

## 安装

1. 从发布页下载 Windows 安装包（`.exe` 安装器）。
2. 双击安装，按提示完成（需要系统已安装 WebView2，Win10 1809+ 通常已内置）。
3. 首次启动会进入引导页：下载本地检索模型（约 200MB，默认使用国内镜像），然后配置称呼。

安装后数据目录：

```
%APPDATA%\night-diary\
├── night_diary.db      # 日记与设置
├── chroma_data/        # 向量索引
├── models/             # embedding / reranker 模型
├── backups/            # 自动与手动备份
└── logs/               # 运行日志
```

## 基本使用

| 场景 | 操作 |
|------|------|
| 写日记 | 首页 → 选择日期格子 → 写作页 |
| AI 分析 | 写完日记后点击「获取 AI 回信」 |
| 历史回顾 | 回顾页按时间浏览 |
| 设置 | 右上角或 `#/settings` |

## 配置 LLM（AI 回信）

夜记的 AI 回信需要联网调用大模型 API（本地只跑检索与编排）。

1. 打开 **设置 → AI 模型**
2. 添加提供商，填写：
   - **Base URL**：如 DeepSeek 填 `https://api.deepseek.com/v1`
   - **API Key**：你的密钥
   - **模型名**：如 `deepseek-chat`
3. 点击「测试连接」确认可用
4. 设为激活并保存

未配置时，日记读写仍可用，但 AI 分析会降级为安全模板。

## 模型下载

首次启动引导页会自动下载：

- `BAAI/bge-small-zh-v1.5`（向量检索）
- `BAAI/bge-reranker-base`（重排序）

下载支持断点续传，默认镜像为 `hf-mirror.com`。若下载失败，请检查网络后重启应用。

## 备份与恢复

- **自动备份**：每次正常退出应用时，Rust 侧会将 `night_diary.db` 复制到 `backups/`，文件名形如 `2026-06-15T143022-auto.db`。
- **手动备份**：设置 → 数据备份 →「立即备份」
- **恢复**：在备份列表中选择文件 →「恢复」→ 建议重启应用

也可直接复制整个 `%APPDATA%\night-diary\` 文件夹做冷备份。

## 常见问题

| 现象 | 处理 |
|------|------|
| 启动卡在「正在连接本地 AI 引擎」 | 等待 15s；仍失败则重启应用或查看 `%APPDATA%\night-diary\logs\` |
| AI 回信为空或模板化 | 检查设置页 LLM 配置与网络 |
| 模型下载慢 | 正常，首次约 200MB；可稍后重试 |
| 安装包体积大 | 含 Python AI 引擎 + PyTorch，约 1–2 GB |

## 卸载

通过系统「应用和功能」卸载夜记。用户数据保留在 `%APPDATA%\night-diary\`，需手动删除才会清除日记。
